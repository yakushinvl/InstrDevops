# Мой пет-проект

Идея: Телеграм-бот для студентов, который присылает расписание пар, напоминает о дедлайнах и предупреждает об изменениях.
Стек: Python, aiogram, SQLite, Docker
Цель: Сделать полезный для группы сервис и развернуть его на сервере.
