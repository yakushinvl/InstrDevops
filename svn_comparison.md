# Сравнение Git и SVN

### 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это просто текстовый файл-указатель размером 41 байт с хешем последнего коммита. Создаётся мгновенно и не занимает места.
В SVN создание ветки — это полное копирование всей папки проекта на сервере. Это долго и тратит место на диске.

### 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя. В SVN есть только один центральный сервер. Если нет связи с сервером — зафиксировать изменения невозможно.
В Git репозиторий полностью хранится локально на компьютере, поэтому коммитить можно офлайн.

### 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
1. Работа с огромными бинарными файлами (тяжёлая 3D-графика, текстуры для игр, видео).
2. Когда нужно скачать не весь огромный репозиторий, а только одну конкретную папку.
3. Когда требуется жёстко ограничить доступ сотрудников к отдельным папкам репозитория.
